# KV design｜让商品成为画面主角 ✨

面向电商商品营销的视觉设计 Skill。它根据真实商品素材、品牌信息和活动需求，帮助 AI Agent 从创意构思走到可审查的实际成图，让商品展示更醒目、营销信息更清楚。

## 🎯 设计对象

适用于需要突出商品与营销主题的视觉任务：商品主视觉、商品主图、促销海报、新品发布图、活动横幅等。无论是新品上架、大促活动，还是品牌日与直播专场，都可以结合商品品类、品牌调性和投放位置设计画面。

建议提供清晰的商品实拍图；Logo、包装细节、品牌规范和风格参考图可帮助更准确地呈现商品。

## 🛠️ 主要功能

- **梳理需求**：识别商品、品牌素材和参考图，整理已确认卖点、必用文案、用途与输出规格。
- **设计主视觉**：围绕商品确定构图、场景、配色、光影和信息层级，让画面有吸引力，也让重点一眼可见。
- **制作与修改**：生成包含商品和文案的实际样图，根据反馈调整指定区域；中英文内容可分别排版。
- **核验与延展**：样图获得明确通过后，制作获准的横幅或其他尺寸版本，并检查商品外观、文字及实际文件规格。

## 🚀 使用方法

1. **安装 Skill**：将完整的 `kv-design` 文件夹放入宿主的 Skills 目录。Codex 可使用 `$CODEX_HOME/skills/`；未设置 `CODEX_HOME` 时使用 `~/.codex/skills/`。
2. **准备素材**：提供商品实拍图，并按需补充 Logo、品牌规范、细节图和参考图；说明投放用途、尺寸、语言、格式、必用文案及已确认卖点。
3. **发起制作**：在对话中输入 `使用 $kv-design`，附上设计要求。先查看实际样图并反馈修改；明确通过某个版本后，再制作约定的尺寸或语言延展。

💡 实际成图需要宿主提供图像生成或编辑工具。如果只需要设计方案或提示词，请在需求中直接说明。

## 📦 输入输出示例

**输入素材：**商品正面实拍图、包装细节图、品牌 Logo。

**输入指令：**

```text
使用 $kv-design 制作新品上市主视觉。
用途：品牌新品宣传；尺寸：1200 × 1200 px，PNG。
风格：浅色背景、柔和光线，突出商品质感。
主标题：新品登场。
请保留商品颜色、结构和包装标签，不添加未经确认的卖点。
先提供样图供我审查；通过后再制作 1200 × 600 px 横幅。
```

**预期输出：**先展示包含商品、标题和 Logo 的实际样图，说明版本与实际尺寸；根据反馈定向修改。样图通过后，重新安排横幅构图并核验尺寸、文案和商品细节，再交付图片。
