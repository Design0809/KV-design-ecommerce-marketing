# KV design｜电商商品营销主视觉

根据真实商品图片、品牌资产和营销需求，从传播定位、构图提案到实际样图与规格交付，支持数码家电、服饰、美妆、食品、家居等品类。

## 两类视觉表达

| 类型 | 适用任务 | 表达重点 |
| --- | --- | --- |
| 销售转化型 | 新品首发、重大促销、活动营销 | 商品与品牌识别、名称、核心利益、真实价格及相关日期 |
| 品牌产品型 | 品牌官网、产品专题、产品营销海报 | 产品效果、形态、材质、使用体验与品牌情绪；信息更精选 |

- 类型由传播目标决定，渠道辅助判断；官网也可做促销，平台也可做品牌产品展示。
- 构图、场景、配色、字体和卖点表达按品牌与商品探索，不固定模板；商品、Logo 与用户锁定信息严格核验。
- 卖点可采用匹配 icon、场景效果、使用小图、真实微距或文字，不要求每项都配图。

## 六个工作模块

1. **资料梳理与范围确认**：识别素材，锁定事实、要求、制作条件与交付清单。
2. **传播定位与信息分级**：确定视觉类型、核心购买理由及阅读层级。
3. **构图探索与视觉表达**：探索三个构图与风格表达有实质差异的方向。
4. **文案定稿与字体编排**：锁定文案，准备各方向的字体、排版和图标策略。
5. **方案选择与样图审查**：G1 选方向后制作实际样图，检查并按反馈修改。
6. **规格交付与延展询问**：按尺寸、格式和数量交付，再询问可选延展。

## G1 三方案选择

- 提供 A、B、C 三张同结构的方案卡片，说明创意、构图、风格、卖点表达与适配理由，同时提供 D“不满意，重新提案”。
- 选择 A／B／C 后深化所选方向并制作样图；选择 D 后重新提供三个与历史未选方案不同的方向，再等待选择。
- 卡片优先使用宿主实际支持的交互组件；不支持时展示文字卡片，由用户回复字母。三案不固定对应某三种风格。
- G1 默认是提案选择，不是三张完整成品；方向确认与实际样图批准分开记录。用户明确改变流程时遵循其要求。

## 使用方法

1. **安装**：将完整 Skill 内容放入宿主可识别的 `kv-design` 文件夹。Codex 可使用 `$CODEX_HOME/skills/kv-design/`，未设置时使用 `~/.codex/skills/kv-design/`。
2. **准备**：提供清晰商品图、正确 Logo、已证实卖点与必显原文，按需补充品牌规范、细节、其他视角及风格参考。
3. **说明**：给出用途、尺寸、语言、格式、数量和可编辑要求；分别标明发售、预售与活动日期。
4. **选择**：调用 `$kv-design`，在 G1 选择 A／B／C 或 D；查看实际样图，反馈修改或明确通过。
5. **交付**：完成本次已约定的全部输出后，可选择追加视角图、卖点图、细节图、场景图或详情页，也可暂不延展。

## 输入输出示例

```text
使用 $kv-design，为附件中的商品制作新品首发主视觉。
类型：销售转化型；用途：电商活动 Banner。
交付：1920 × 1080 px，PNG，中文版与英文版各 1 张，共 2 张。
商品、品牌 Logo、名称、首发价和发售日以附件为准，标为必用的原文完整保留。
从已证实卖点中选一个核心购买理由，其他卖点按需要使用 icon、使用小图或文字。
第五模块先以 G1 卡片提供三种不同构图与风格的方案，以及 D 不满意选项。
我选择后再制作中文版样图，通过后完成约定的英文版，英文独立排版。
全部交付完成后，再询问我是否需要追加卖点图或商品详情页。
```

品牌产品型任务可明确：“以产品形态、材质与品牌体验为核心，不强加促销价格；三个方向均须符合我的品牌规范”。实际图像生成与导出能力由宿主提供，方案或 Skill 分析任务不会触发成图。
