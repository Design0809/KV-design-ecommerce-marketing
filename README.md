# KV design｜让商品成为画面主角 ✨

面向电商商品营销的视觉设计 Skill。它根据真实商品素材、品牌信息和活动需求，帮助 AI Agent 从创意构思走到可审查的实际成图，让商品展示更醒目、营销信息更清楚。

## 🎯 设计对象

适用于需要突出商品与营销主题的视觉任务：商品主视觉、商品主图、促销海报、新品发布图、活动横幅等。无论是新品上架、大促活动，还是品牌日与直播专场，都可以结合商品品类、品牌调性和投放位置设计画面。

建议提供清晰的商品实拍图；Logo、包装细节、品牌规范和风格参考图可帮助更准确地呈现商品。

## 🛠️ 主要功能

- **判断品牌与场景**：根据品牌依据、产品价值、真实使用关系和展示条件选择视觉方向；区分规定、推断与设计假设，避免跨产品套用同一暖色、冷色或构图。
- **筛选购买理由**：区分必须展示、可压缩和仅作依据的信息；新品突出商品、型号与一个核心广告语，首发价形成独立转化重点。
- **联合设计图文**：同时安排产品、标题、价格和辅助信息，再深化光影与场景；通过轮廓对比、材质和留白形成主次，避免商品顶边与僵硬分栏。
- **表达功能卖点**：按信息需要选择功能使用小图、材质微距、图标或文字；有依据的主效果与辅助小图分工，数量由画幅与实际可读性决定。
- **设计广告标题**：先建立关键词、字重与断行层级，再选择符合品牌的局部表现手段；渐隐仅用于仍完整可读的穿插。中英文分别排版，保留事实与信息优先级。
- **制作与修改**：按工具能力生成完整样图，必要且获授权时采用分层制作，记录已认可与尚未评价内容，检查修订是否损害原有张力、层级和呼吸空间。
- **核验与延展**：分别检查视觉主次、商品事实和实际文件规格；默认样图通过后制作约定延展。

## 🚀 使用方法

1. **安装 Skill**：将完整的 `kv-design` 文件夹放入宿主的 Skills 目录。Codex 可使用 `$CODEX_HOME/skills/`；未设置 `CODEX_HOME` 时使用 `~/.codex/skills/`。
2. **准备素材**：提供商品实拍图，并按需补充 Logo、品牌规范、细节图和参考图；说明投放用途、尺寸、语言、格式、必用文案及已确认卖点。将必须原文显示的内容单独标明，分别注明发售日与优惠区间。
3. **发起制作**：在对话中输入 `使用 $kv-design`，附上设计要求。先查看实际样图并反馈修改；明确通过某个版本后，再制作约定的尺寸或语言延展。

💡 实际成图需要宿主提供图像生成或编辑工具。如果只需要设计方案或提示词，请在需求中直接说明。

## 📦 输入输出示例

**输入素材：**商品正面实拍图、包装细节图、品牌 Logo。

**输入指令：**

```text
使用 $kv-design 制作新品上市主视觉。
用途：智能家电新品营销 Banner；尺寸：1920 × 1080 px，PNG，中文版。
品牌、型号、首发价和日期按附件准确显示，已标明的原文必须保留。
从产品资料中选一个核心购买理由拟广告语，产品与广告语为主要视觉重点，型号清楚，首发价醒目。
先根据品牌特色、产品功能和真实使用情境决定场景与表达方式。
辅助卖点按理解需要使用功能小图与短文案、微距、图标或文字；有依据时用一个主效果强化核心利益。
参考图分别用于光影与功能表达，不照搬其品牌、参数或商品结构。
字体符合品牌且有广告表现力；画面有疏密、空间和轮廓对比，标题完整可读，保留商品颜色、结构与包装标签。
先展示样图供我审查，通过后再制作同尺寸英文版；英文独立排版。
```

**预期输出：**先展示包含商品、品牌、型号、核心广告语、价格和必要辅助信息的实际样图，说明版本与实测尺寸；根据反馈定向修改。样图通过后，按约定制作英文版并逐张检查后交付。
