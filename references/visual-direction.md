# 视觉方向、标题与空间判断

用于从 Brief 探索方向、准备 G1 三方案，以及处理“太冷、太平、遮挡、拥挤”等反馈。这里提供判断方法，不规定统一的品类风格。

## 从资料到设计决策

| 维度 | 判断依据 | 转为具体选择 |
| --- | --- | --- |
| 品牌 | 规范、现有视觉、包装与用户定位；包装推断须注明 | 字体性格、色彩边界、材质语言与表达强度 |
| 核心价值 | 证实卖点、购买动机与营销目标 | 核心广告语、视觉概念与卖点呈现方式 |
| 外观 | 商品轮廓、颜色、材质、组合关系和已知视角 | 主体尺度、局部对比、光向与空间关系 |
| 使用情境 | 谁在何处、何时使用，商品与环境如何接触 | 场景、相关道具、情绪与物理关系 |
| 视觉类型 | 销售转化型／品牌产品型及主次目标 | 商品、名称、价格、日期与利益的视觉权重 |
| 展示条件 | 画幅、实际显示大小、安全区、必显信息 | 信息容量、文字行数、卖点形式和适配方法 |

- **记录因果**：`资料依据 → 判断（明确规定／推断／假设）→ 视觉选择 → 预期阅读顺序`。
- **比较购买理由**：资料支持多个利益时，比较受众相关性、可信依据、差异价值和视觉表现潜力。无需机械评分；选择能说清且能成立的传播核心，不把数值最大等同于最有吸引力。
- **区分两类**：销售转化型强调购买信息的发现与理解，品牌产品型强调产品与品牌体验；两类都需要商品准确、信息清楚。促销可以克制，品牌表达也可以鲜明丰富。
- **形成混合主次**：例如“品牌产品呈现为主，首发价格为清楚可见的次重点”；不把两类的全部元素同时放大。

### 三方案的构图与风格差异

- **共同基线**：三案使用相同 SKU、品牌规范、视觉类型、传播核心、必显文案和交付条件，比较的是视觉方向。方向编号不对应固定风格。
- **构图差异**：观察主体与文字的组织关系、空间结构及观看动线。中心聚焦、非对称场景、对角引导、环绕组织、局部特写或组合叙事均可考虑，但不得为了差异重造商品视角。
- **风格差异**：比较场景语言、光影组织、材质氛围、字体性格及情绪。颜色可以参与差异，但不能成为唯一差异。
- **差异记录**：每案用一行记录 `编号／轮次 → 商品与图文关系 → 空间／动线 → 场景与光影 → 字体／材质 → 卖点表达`；用于本轮两两比较和 D 后历史比较。
- **差异判断**：去掉方案名称和色彩描述后，两案仍应能从构图和表达方法上区分。不能把相同左文右图仅换背景色后称为三种方向。
- **约束内创新**：固定 Logo、字体或品牌色时，从构图、场景、光影、空间与材质寻找区别，不突破品牌规范凑三案。用户锁定构图时优先保持，确实无法提供三种构图则说明冲突。
- **D 后重提**：保留事实与要求，围绕反馈更换构图和风格组合；新案与历史未选方案须有实质差异，但可以保留用户明确喜欢的局部特征。不将无理由的 D 推断成对某种色彩或品牌方向的永久否定。

### 类型内的探索示例

| 同一任务 | 可探索的方向 | 共同约束 |
| --- | --- | --- |
| 服装新品转化 | 商品与价格成组的中心陈列／穿着场景的非对称编排／织物细节与完整衣物的编辑式组合 | 品牌、名称、首发价与日期清楚；版型、花纹及材质不变；模特路线须符合任务 |
| 美妆品牌产品 | 包装的雕塑式光影／真实质地与瓶身的近远关系／有依据的使用情境叙事 | 保留包装、标签、颜色和核心概念；质地、成分和功效须有依据 |
| 家电品牌产品 | 环境中的纵深叙事／克制的产品与文字对照／围绕已证实功能的动线表达 | 产品结构与视角真实，功能表达正确，不默认冷色科技背景 |

以上仅说明探索方法，不要求每次照搬三种主题或附加画面元素。G1 卡片与选择行为见生成配方。

## 场景情绪与产品表现

- **生活温度**：可来自自然光、木材／织物和少量使用痕迹，不等于橙黄滤镜；人物、宠物、餐食和道具须与任务相关。
- **主体识别**：温暖浅色场景也须保留浅色商品轮廓；通过局部明度、侧光、阴影或冷暖差解决，不统一改成深色。
- **表达强度**：精密克制仍需商品与标题的力度；年轻鲜明也不要求每处都高饱和、大字或发光。
- **功能与氛围**：使主效果的方向、色温和密度与场景协调；不通过删除必要功能表达换取整洁，也不为冲击力增加无关特效。
- **感官与材质**：非功能性商品可依靠真实材质、形态、姿态、搭配和排版建立吸引力。食品、衣物、美妆不套用数码渲染语言。

## 标题：先排版，再选择表达手段

- 先检查关键词、行数、字形、字重、字距、尺度和对比，再决定效果；标题在去掉效果后仍须有主次。
- 销售转化型可强化活动主题或真实利益，但品牌、名称和条件不能被淹没；品牌产品型可精简标题，但不把细字和小字等同于品质。

| 希望表达 | 可尝试的方法 | 检查重点 |
| --- | --- | --- |
| 精密、有力 | 稳定字形、局部字重／尺度对比、受控质感 | 避免全句同重或仅剩均匀细字 |
| 动势、效率 | 语义断行、方向性编排、关键词与效果呼应 | 不以粗斜体作为唯一方法，方向与功能一致 |
| 亲和、感官 | 符合包装的字形、柔和颜色或真实材质呼应 | 不失去可读性，不暗示虚构原料或功效 |
| 品质、工艺 | 空间秩序、真实细节、受控色阶与精确排版 | 不固定黑金、衬线、金属渐变或大面积空白 |

- 少量有主题依据的表达即可；字体文件、精确透明度等由实际制作核验，生成提示词不等于准确应用。

## 穿插与渐隐的适用条件

- 优先用空间、光影、视线或跨区效果联系图文；穿插不是构图合格的必要条件。
- 标题冲突时比较错位、尺度、位置和层次；渐隐只是候选方式，实际显示大小下必须无需猜测即可完整阅读。
- Logo、型号、金额、币种、日期和优惠条件不用遮挡或渐隐制造氛围；效果造成缺字、歧义时返回布局。

## 疏密与阅读停顿

- 将主要聚焦区、辅助信息区与视觉缓冲区理解为空间角色，不是三个固定矩形；主体尺度与留白不设通用百分比。
- 关联文字可紧凑成组，语义独立的辅助句可成为次级阅读点；不机械移动所有副标题。
- 从可见笔画、轮廓、阴影与光效外缘判断距离；边界框不相交不代表视觉不拥挤。
- 缓冲区允许低复杂度场景；避免高对比道具、强纹理和光带挤占阅读停顿。
- 容量不足先删非必需装饰、精简可编辑文案，再调整主体、位置或小图数量；必显信息完整保留。

**完成条件**：三案各自成立且差异清晰；所选成图有符合任务的焦点、准确可读的信息、清楚商品轮廓和有意图的空间节奏。最终质量以实际成图判断。
