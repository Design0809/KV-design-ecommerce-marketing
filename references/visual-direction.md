# 视觉方向、标题与空间判断

从 Brief 选择方向，以及处理“太冷、太平、遮挡、拥挤”等反馈时读取。本文件提供判断条件；品牌规范与本次任务优先，不输出统一的家电、美妆或食品模板。

## 从资料到设计决策

| 维度 | 判断依据 | 转为具体选择 |
| --- | --- | --- |
| 品牌 | 规范、现有视觉、包装与用户定位；若仅凭包装推断须注明 | 字体性格、色彩边界、材质语言、表达强度 |
| 核心价值 | 已证实功能、购买动机与营销目标 | 一个核心广告语，以及能否用主场景效果说明 |
| 外观 | 真实轮廓、颜色、材质、套装关系与可用视角 | 主体尺度、背景局部对比、光向和商品前后关系 |
| 使用情境 | 谁在何处、何时使用，产品与环境怎样接触 | 场景、少量相关道具、情绪和物理关系 |
| 营销模式 | 新品认识、促销转化、功能解释或品牌形象 | 标题、型号、价格、功能信息的优先级 |
| 展示条件 | 画幅、实际显示大小、平台安全区、必显内容 | 信息容量、小图数量、文案行数与适配方式 |

用简短记录串起因果：`资料依据 → 本次判断（明确规定／推断／假设） → 视觉选择 → 预期阅读顺序`。形成一个主推方向即可；无需为证明思考过程生成多套图片或新增确认关卡。

例如，品牌强调亲和、产品用于日常家庭清洁，可选自然光与有触感的家居材质；若同类产品主打专业精度且品牌要求冷色，则可选择受控冷光与更简洁的空间。品类只是起点，不能替代品牌判断。

## 场景情绪与产品表现

- 生活温度可来自光照时段、木材／织物、人的使用痕迹和合理尺度，不等同于橙黄滤镜。道具需与使用有关，不自动加入人物、宠物、餐食或多件商品。
- 温暖环境中也要让浅色产品保持轮廓；可调整产品背后局部明度、阴影、冷暖差，而非把整张图改为深色。
- “精密、克制”仍需有主体对比和主标题力度。“年轻、有活力”也不能让每个信息块同时高饱和、大字、发光。
- 主功能效果与环境情绪可共存：调整效果的色温、密度和方向，使其解释已证实功能。不能通过删光效果来换取整洁，也不为恢复冲击力增加无关特效。
- 没有适合可视化的功能时，依靠真实材质、产品姿态、光影和排版建立广告表现力。

## 标题：先排版，再选择表达手段

先检查关键词、行数、字形、字重、字距、大小与对比，再考虑效果。标题应在没有效果时仍有主次。

| 希望表达 | 可尝试的方法 | 检查重点 |
| --- | --- | --- |
| 精密、有力 | 清晰正体、局部字重或大小对比、克制的材质光泽 | 不能只剩均匀细字，也不以全句厚重立体字代替层级 |
| 动势、效率 | 语义断行、方向性排列、关键词与使用效果呼应 | 方向符合功能，不默认运动斜体 |
| 亲和、感官 | 与包装一致的字形性格、柔和局部颜色或质感 | 不臆造功效，不因柔和失去识别 |
| 高端材质 | 留白、真实纹理呼应、受控色阶 | 不固定黑金、香槟铜、衬线或细体 |

选择能强化主题的少量手段，记录应用区域和强度。生成式文字不能承诺准确字体文件或精确透明度；需要准确控制时按主流程评估允许的分层路线。

## 穿插与渐隐的适用条件

优先通过共同地面、视线方向、空间纵深、光影或跨区效果联系图文。可读的穿插是候选，不是合格构图的必要条件。

当产品与标题下缘产生冲突，可比较错位、调整主体尺度、移动标题、改变层次，以及标题下缘渐隐。采用渐隐时，上部笔画清晰，下部逐渐减弱；不规定统一渐变起点、颜色或百分比。核心字形必须保留，实际显示大小下无需猜测即可读完整句。

型号、金额、币种、日期、优惠条件及 Logo 不用渐隐或遮挡制造氛围。标题渐隐后仍有歧义，或英文关键字母被挡住，就返回布局调整；不能仅凭提示词写了“渐隐”判定通过。

## 疏密与阅读停顿

将画面组织为主要聚焦区、辅助信息区与视觉缓冲区。这些是空间角色，不是三个固定矩形：主要聚焦区也应有局部留白，辅助信息可按语义分布在多处。

- 标题与辅助句联系紧密、容量合适时可成组；辅助句成为情绪或利益补充、且上方拥挤时，可移为独立次级阅读点。维持语义与对齐关系，不机械下移所有副标题。
- 从可见笔画、产品外轮廓、阴影和光效外缘检查净空；文字框不相交不代表不拥挤。语义不同的组不应因距离太近被误读为同一标题。
- 视觉缓冲区可有低细节环境，避免高对比道具、强纹理或光带挤占。留白的用途是分组、突出与停顿，不是追求空白面积数值。
- 空间不足先删非必需装饰、精简可编辑文案，再调整位置、主体尺度或小图数量；必显内容不能擅删，也不能把所有文字统一缩小。

完成条件：看得出主次，标题完整，商品轮廓清楚，辅助句能独立读懂，价格可定位，小图可理解，密集区之间有停顿。具体结果须用实际成图检查，不承诺仅凭规则就自动达到某种审美评价。
