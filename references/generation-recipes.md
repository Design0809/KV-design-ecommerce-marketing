# 生成与迭代配方

进入实际制作时读取。先完成信息取舍与图文联合试排，再把决策写入提示词；不能仅堆叠“高级、干净、有冲击力”等形容词。以下方括号是填写说明，调用工具前替换真实内容并删除无关字段。

## 完整成图提示词骨架

```text
任务：制作一张[新品／促销／品牌／功能说明]主视觉[审查样图／已批准范围内的延展]。
交付目标：[宽] × [高] px，[比例]，[横／竖]，[格式]；这是目标规格，生成后另行读取文件核验。
输入角色：[图1：同 SKU 商品身份；图2：真实细节；图3：仅参考整体光影；图4：仅参考功能窗]。
身份锁定：[具体轮廓、比例、颜色、材质、Logo、结构、配件数量及保留视角]。
视觉策略：[品牌规范／资料判断／设计假设]支持[品牌气质与产品价值]，使用情境为[人群／地点／使用关系]，因此选择[场景情绪、配色与表达强度]；不照搬上一产品的风格。
传播目标：[受众]看到[产品及一个已证实购买理由]，随后注意[型号／首发价等]。
阅读顺序：[第一视觉组] → [第二视觉组] → [辅助信息]；避免所有信息等大等粗。
联合构图：[产品组合位置及包围框、标题行数与边界、型号位置、价格区、辅助功能带、日期位置]。
空间关系：[共同地面／前后层次／光线联系]；[关键边缘]净空；主要聚焦区[位置与关系]、辅助信息区[分组]、视觉缓冲区[范围及背景细节控制]，保护[关键结构与文字]。
穿插处理：[无需重叠／错位／可读穿插等]；仅确需渐隐时写明[区域、方向、必须保留的笔画与可读要求]，不让型号、价格或条件被遮挡。
轮廓与光影：[商品背后区域的明度／色温差、主光方向、边缘光、接触阴影、背景细节控制]。
配色：[主色与辅助色]；强调色集中于[核心词／价格／主功能效果]，不改变商品本色。
功能可视化：[无需主效果，或证实事实对应的部位、方向与一个具体效果]；[效果与环境的色温、密度联系]。
辅助卖点：[逐项选择功能使用小图／微距／图标／短文字及理由]。小图写明[同 SKU 依据、外部可见动作、环境关系、短文案、边界、位置与大小]；图标写明[语义、线宽与短标签]。不使用的形式删除，视觉重量低于主体、型号和主标题；以实际显示大小检验可理解性。
逐字可见文案：品牌“……”；型号“……”；主标题“……”；辅助句“……”；卖点“……”；价格“……”及条件“……”；[发售日或优惠区间]“……”；[必要示意标注]“……”。不新增其他营销文字。
字体：[品牌与品类适用字形]，主标题[关键词、字重／最大行数／宽度]，选择[无附加效果或有理由的局部表现手段、应用范围与强度]，型号[关系]，价格金额[突出方式]，其余文字[弱化方式]。
辅助广告语：[与标题成组或独立阅读点及理由]，明确[相对位置、换行与组间净空]，不与标题效果或产品轮廓挤在一起。
语言：[本版语言]；按语义独立断行，品牌、型号、数字、单位和优惠含义锁定。
保留项：[用户明确认可的优点与仍有效的修改要求]；尚未评价项：[内容]，不将其记为批准。
避免：[本次最可能出现的具体失败，如基站顶边、浅机身融入墙面、四卖点同重、英语大段粗斜体]。
事实边界：不改 SKU，不补造内部结构，不引入参考图的品牌、参数、认证、配件或促销。
```

在执行记录中另记样图审查状态、工具能力及导出方式；这些制作说明不成为画面文案。完整成图必须包括该版本全部锁定信息；仅生成无字底图时明确标记内部素材，不能当作完成样图。

## 分层制作路线

适用于准确 Logo／指定字体／复杂文字／可编辑源稿等要求，须符合本次授权和宿主工具规则；本配方不授权绕过图像编辑工具限制。

1. 确定精确画布、可用字体、产品原图和 Logo 文件，记录每个图层边界与前后关系。
2. 用图像工具完成需要生成的场景、光影及功能效果。背景留出有意设计的文字空间，禁止出现伪造文字、重复产品或其他品牌。
3. 在允许的排版／合成工具中放置原商品资产、Logo、准确文字及统一图标；商品与背景光向、边缘和接触阴影需融合。需要产品保真时避免重复重绘原商品。
4. 按目标尺寸实际渲染，核验字体替换、透明边缘、功能图窗、价格条件、像素规格和可编辑范围。

图层可按 `背景 → 环境效果 → 商品 → 局部功能窗 → 品牌／文字／图标` 组织，按遮挡关系调整；不是必须照搬的固定顺序。若原商品与背景无法自然融合，返回视觉制作，不用虚假的阴影或变形硬拼。

## 定向修改

每轮同时提供当前稿和原始商品依据，必要时补充本轮专用参考，不只在已漂移的生成稿上继续修改。

```text
图1是[语言／版本]当前稿，图2是商品身份依据，图3仅参考[局部规则]。
仅修改[区域与问题]：将[当前状态]调整为[可观察的目标]。
保留[商品身份、其他语言版本、已接受构图、文案与尺寸，以及原有功能张力／场景情绪等明确认可的优点]；尚未评价[内容]，不擅自视为已认可。
可见文案逐字为：[本轮完整锁定清单]。
本轮可能影响：[邻接文案／标题光效外缘／主体尺度／场景或功能效果]。
本轮检查重点：[问题是否解决]，并回查[标题完整性／型号辨识／价格权重／疏密／功能张力／轮廓对比／小图可理解性]，不得以牺牲已认可优点换取局部通过。
不得改变[未涉及结构与信息]；生成后重新检查事实与规格。
```

| 反馈 | 具体修改方向 |
| --- | --- |
| 没有重点 | 根据传播目标重新安排阅读顺序，减轻辅助卖点，单独组织型号和价格；不要把全部内容一起放大 |
| 产品太大 | 收缩产品组合包围框，保留机身比例及前后关系，释放指定边缘净空，不强裁产品 |
| 画面很平 | 调整商品背后区域明度、边缘光、接触阴影与背景细节；不直接增加多种饱和色 |
| 文案像说明书 | 保留一个核心利益标题，辅助句解释，次级事实按理解需要转为小图短文案、图标或短文字；不擅删锁定内容 |
| 图文割裂 | 用空间、光向和地面联系两区，必要时调整跨栏关系；不强行让产品挡住文字 |
| 字体像运动广告 | 按品牌换稳定正体，调整字重和行长；继承已接受的标题尺度及留白 |
| 功能窗抢主体 | 降低其面积、亮度或效果密度，必要时取消非必需图窗；必显信息保留，不靠放大整机补偿 |
| 缺少生活感／太冷 | 核对品牌与使用情境后调整自然光、触感材质与少量相关道具；保留主体轮廓和功能效果，不统一加黄 |
| 标题太平 | 先增强关键词、字重、大小和断行关系，再选择符合品牌的局部色彩或质感；不一律变细、变斜或加立体效果 |
| 标题被产品遮住 | 先试错位、尺度或层次；渐隐仅在完整可读时使用，否则重新排版 |
| 辅助句拥挤 | 从标题效果和字形外缘检查距离，按语义决定分组或独立下移；不将所有文字一起缩小 |
| 小图看不懂 | 检查动作与产品身份，简化视角与效果、减少图数或改文字；不要补造结构来增加细节 |
| 改完后没有原来的张力 | 对照已认可版本，恢复有依据的主效果或主体对比，并适配新场景；不重新堆满所有装饰 |

## 家电新品迁移示例

以下仅演示信息分工，必须以本次资料验证，不能把示例数值、品牌或价格作为默认内容。

假设资料确认某扫地机器人具有吸尘、建图、避障和基站洗烘功能，并提供首发价与优惠区间：

- 核心主题选择其中一个购买理由；主标题表达该理由，参数作为证据，不让参数自动淹没商品名。
- 产品与核心广告语构成第一视觉组，型号显著高于次级卖点，金额是独立转化重点；优惠区间按其含义标注，不改称发售日。
- 若选择吸力主题，可用原视角外部颗粒轨迹表现；辅助功能按信息需要选择使用小图或短标签，例如有资料支持的沿墙清洁可用外部场景小图。没有底部图时，不生成吸口剖面。
- 若改为洗烘主题，只在有对应部位依据时用局部窗解释过程；缺少依据时采用文字与真实外观。主场景只保留服务当前核心主题的主要效果，辅助小图中的机制表达降低视觉重量。
- 中文与英文分别试排；英文正体与语义断行不受中文坐标限制。

## 其他品类迁移示例

- 护肤瓶：绿色方瓶实拍，资料只说明便携。保留瓶形／泵头／标签，用包装与携带场景表达，不从植物道具推断配方、修护或美白；无需套用家电功能窗。
- 耳机：黑色耳机与盒子，资料只说明通勤。受控高光、稳定文字和合理空间，不虚构降噪、续航或防水，不为了科技感画内部芯片。
- 餐椅：橡木餐椅侧前实拍。用空间、侧光和真实纹理突出产品，不新增扶手／软垫，不凭图像宣称纯实木或环保认证。

## 工具受限

- 不支持精确尺寸：制作前确定授权范围内的精确导出方案，禁止拉伸商品或强裁关键信息。仍不满足时保留内部稿并说明未完成。
- 无图像工具：说明尚未生成样图，可保留设计决策和提示词，不以文字方案或 SVG 商品替身冒充成图。
- 字体／Logo 无法准确执行：优先用已授权的分层方式；不可用时说明具体限制，不宣称原始矢量或指定字体已应用。
- 网络失败、样图审查与延展范围遵循主流程，不把失败或保存提示词记为已交付。
