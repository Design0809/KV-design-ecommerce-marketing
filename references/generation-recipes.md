# 生成与迭代配方

准备 G1 卡片、实际制作或定向修改时读取。先完成传播与视觉判断，再将决策转为执行约束；方括号是模板字段，使用前填写真实内容并删掉无关项，不将内部记录放入画面。

## 完整成图提示词骨架

### G1 卡片与选择

- 卡片展示本轮视觉类型、共同核心与目标规格，再并列或依次展示三个同结构的方向；不要要求用户阅读长提示词。
- 优先使用宿主实际支持的卡片或选择工具，选项为 `A｜本案名称`、`B｜本案名称`、`C｜本案名称`、`D｜不满意，重新提案`，不预选等同于用户提交。
- 若工具限制选项数量、不可用或当前模式不允许调用，使用以下文字卡片，让用户回复字母及可选意见；不删去 D，不伪造交互按钮。
- 布局示意为可选辅助，明确标注“方案示意，非实际成品”；G1 不要求先完成三张商品成图。用户特别要求三张视觉预览时按其范围执行并正确标注状态。

```text
G1｜第 [轮次] 轮
类型：[销售转化型／品牌产品型及具体目标]
共同依据：[商品、核心购买理由、锁定信息、规格]

A｜[方案名称]
创意：[一句话说明表达方法]
构图：[商品与文字关系、空间、动线及留白]
风格：[场景、光影、材质与字体性格]
卖点：[采用的 icon／效果／小图／微距／文字及分工]
适配：[品牌与资料依据、表现侧重或取舍]

B｜[方案名称]
创意：[内容]
构图：[内容]
风格：[内容]
卖点：[内容]
适配：[内容]

C｜[方案名称]
创意：[内容]
构图：[内容]
风格：[内容]
卖点：[内容]
适配：[内容]

D｜不满意，重新提案
重新提供三个构图与风格表达不同的方案；可以附上希望改变或保留的内容。

请选择 A、B、C 或 D，也可附带修改意见。
```

| 用户回应 | 执行行为 | 更新记录 |
| --- | --- | --- |
| A／B／C | 完成所选方向必要定稿，制作实际样图 | 轮次、方案、选择原意 |
| A／B／C＋意见 | 整合意见；无实质冲突时直接制作 | 修改内容、必须保留项 |
| D | 提出新一轮三个不同方向，再次等待 | 旧案构图与风格特征、新案差异 |
| D＋反馈 | 将反馈转为新约束，重新提供三案 | 不喜欢的原因、明确保留项 |
| 明确的自然语言选择 | 可唯一对应本轮方案时按选择处理 | 对应方案及用户原意 |
| 未回答或含义不明 | 等待；歧义影响执行时简短澄清 | 不记录批准，不开始完整样图 |

- 每次 D 仅触发一轮三案，禁止无限自动生成；新案与本轮其他方案及历史未选方案均在构图和风格表达上有实质差异。
- 未给原因时不推断永久偏好；用户已经明确保留的元素可以继承，不为差异牺牲事实、Logo 或必显内容。
- 方向、样图、延展范围分别记录；G1 选择不能写成“样图通过”。用户明确授权调整流程时遵从，不反复索取同一授权。

### 所选方向的成图提示词

```text
任务：制作[视觉类型／具体目标]的[实际审查样图／已批准范围内延展]。
方向：G1 第[轮次]轮[方案]已选定；纳入[本轮有效反馈]。
规格：[宽]×[高] px，[比例／方向]，[格式／透明要求]；生成后以文件核验。
输入角色：[商品身份图、同 SKU 细节图、正确 Logo、仅参考场景／光影的图片]。
商品锁定：[具体轮廓、比例、颜色、材质、结构、标签、配件数量及有依据的视角]。
Logo 锁定：[正确版本、形状、拼写、比例、颜色、位置与净空要求]，不混入参考品牌。
视觉依据：[明确规范／资料判断／设计假设]支持[核心概念与场景情绪]。
传播重点：[受众]先注意[第一视觉组]，再注意[名称／利益／价格等次重点]。
联合构图：[主体关系与边界、文字块与行数、必要价格区、卖点位置和缓冲空间]。
光影空间：[主光、局部轮廓对比、支撑面、阴影、反射、场景细节与透视]。
配色材质：[有品牌依据的视觉选择]；保留商品本色与真实表面。
主卖点：[已证实事实、作用部位／方向及具体表达；无需效果时删除]。
辅助卖点：[每项选择 icon／使用小图／微距／短文字及依据、位置、权重]。
icon：[语义、统一风格、线宽／填充、视觉尺寸与标签关系；不用时删除]。
逐字文案：[品牌、名称／型号、标题、辅助句、卖点、必要价格条件与对应日期]。
字体排版：[字形策略、关键词、字重、最大行数、块宽、组间净空与必要局部表现]。
语言：[本版语言与断行要求]；数字、单位、价格和业务含义锁定。
保留项：[用户明确认可内容]；尚未评价项：[内容，不记为认可]。
本次重点避免：[最可能发生的具体错误，不堆砌无关禁令]。
```

- 不把“高级、干净、有冲击力”当作可执行构图；写明商品、图文关系、光影和阅读顺序。
- 不给品牌产品型强加价格、日期与促销按钮，也不让销售转化型遗失已要求的购买信息。
- 无字背景只是内部素材；实际样图须包含该版全部锁定可见信息。

## 分层制作路线

1. **确认资产**：精确画布、可用且允许使用的字体、商品原图、正确 Logo 与图层关系；从第一模块继承制作路线。
2. **制作视觉**：用当前允许的图像工具生成场景、光影与必要功能效果，按联合构图保留文字空间，避免伪字、重复商品与其他品牌。
3. **组合信息**：在授权及工具规则允许范围内控制商品、Logo、文字和 icon；原商品与背景的光向、边缘、透视和接触阴影应自然。
4. **实际渲染**：核对字体替换、透明边缘、文字、Logo、卖点图、规格及可编辑范围；无法自然融合时返回视觉制作，不变形商品硬拼。

- 图层可按 `背景 → 环境效果 → 商品 → 局部说明 → 品牌／文字／icon` 组织，按遮挡关系调整，不是固定层序。
- 原商品层保留与生成重绘分开记录；只提供商品图作为参考不等于像素级保真，只提供 Logo 参考不等于嵌入原矢量。
- 现有授权可复用；宿主要求其他图像编辑方式另行授权时遵守。本文件不扩大工具权限。

## 定向修改

每轮同时提供当前稿与原始商品依据，需要时补充正确 Logo 或局部参考；避免只在漂移稿上叠加修改。

```text
当前稿：[语言／版本]；原商品依据：[素材]；正确 Logo：[素材]。
仅修改：[区域与具体问题]，目标：[可观察的变化]。
保持：[商品身份、锁定文案、规格、未涉及版本与用户认可的视觉优点]。
完整可见文案：[本轮锁定清单]；尚未评价：[内容]。
可能影响：[邻接文案／轮廓／标题外缘／功能效果／空间]。
检查：[本轮问题]是否解决，以及[保留项]是否仍成立。
```

| 反馈 | 优先修改方向 |
| --- | --- |
| 没有重点 | 按本次类型重排注意力，减轻辅助信息；不将所有元素一起放大 |
| 产品太大或拥挤 | 调整组合边界与位置，释放受压边缘；不拉伸或裁掉关键结构 |
| 图文割裂或画面很平 | 调整图文关系、局部明度、主光与接触关系；不只堆饱和色 |
| 文案像说明书 | 保留核心利益，按理解需要分配 icon、小图、微距和文字；不删必显项 |
| 风格不符品牌 | 回到品牌依据调整字形、材质、场景与强度；不机械换成细字或黑金 |
| 标题遮挡或辅助句拥挤 | 调整位置、尺度、分组及实际字形外缘间距；渐隐仍须可读 |
| icon 看不懂或暗示过多 | 更换语义明确的图标、补短标签或改文字；不新增功能承诺 |
| 小图抢主体或看不懂 | 简化动作和效果，调整面积与对比，必要时减少小图 |
| 改完失去原来优点 | 对照认可版本恢复有依据的表现，并适配本次修改，不重新堆满装饰 |

## 家电新品迁移示例

- 资料证实某清洁家电的功能并提供首发价与活动区间时，可按销售转化型组织商品、名称、核心价值与价格；优惠区间不能改成发售日。
- G1 可探索不同空间与文字关系，但共用同一已证实核心，不把每案改成不同商品或不同营销任务。
- 主功能适合可视化时用一个有依据的效果，其他简单功能可用 icon＋短标签；内部洗烘结构无素材时不画剖面。
- 英文与中文分别试排，不复制坐标或默认粗斜体。

## 其他品类迁移示例

- **护肤瓶**：只证实便携时，可展示包装、携带情境或对应 icon；不从植物道具推出配方、美白或修护。
- **衣物**：有面料细节与版型依据时，可采用整体衣物与微距组合；不为品牌质感修改花纹、Logo 或面料。
- **食品**：以真实包装、食物和食用情境建立吸引力；不臆造配料、份量和健康效果。
- **餐椅**：通过空间、侧光和真实纹理表达产品；不新增扶手或软垫，不凭外观宣称纯实木或认证。

## 工具受限

- **卡片能力**：按实际可用工具与模式调用；文字卡片＋字母回复是完整备用交互，不宣称其可点击。
- **尺寸导出**：制作前确认允许的精确导出路线；不能满足时说明未完成，不以拉伸商品、改文件名或改 DPI 代替。
- **图像能力**：无生成工具时可保留方案和提示词，但明确尚未生成样图；不以商品替身或线框冒充成品。
- **Logo／字体**：无法准确执行时优先采用允许的原资产与分层控制；仍不可用则说明具体限制，不声明已准确应用。
- **原图获取**：视角、内部或细节不足时请求相关素材；明确授权的概念图与真实商品图分开标注和交付。
- **结果展示**：按宿主工具返回机制展示真实图片与文件；内置图像工具的 code mode 使用其要求的 `generatedImage`，不输出 base64 或虚构下载地址。
- **失败处理**：重试、样图批准和延展范围按主流程，不把失败调用或保存提示词记作交付。
