# 主视觉验收

每次样图展示前、定向修改后及最终延展交付前读取并执行。检查实际渲染结果，不只审阅提示词。按当前传播目标判断；新品的价格权重不机械应用到无价格的品牌图。

## 观察方式

1. 打开实际文件并与原商品、品牌和锁定文案对照，检查结构与文字细节。
2. 在目标展示尺寸观察可读性；另用缩略预览判断注意力顺序。缩略图用于看主次，不要求所有辅助文字在极小预览中都可读。
3. 明度关系难判断时，可使用工具允许的灰度或弱化细节预览辅助观察；这不是必须新增的交付图。
4. 记录通过／需修改／无法验证及具体区域。文件检查、视觉判断和用户批准分开，不能用一个总分掩盖事实或规格错误。

## A. 事实与商品身份：必须通过

- 商品轮廓、比例、颜色、结构、材质、接口、按钮、Logo、标签与数量符合原素材；无错误配件、未证实内部构造或生成漂移。
- 品牌、型号、每项锁定文字、价格、币种、单位、条件与日期准确，无错字、乱码或缺字。发售日、预售日和优惠区间没有被混淆。
- 可编辑文案的利益表达有资料支持；图标、效果及画面没有加入无依据认证、除菌、精度、赠品或折扣。
- 功能效果作用于正确部位与方向；热水洗拖布没有变成热水洗地，热水没有变成蒸汽灭菌；参考图参数未进入本商品宣称。
- 无素材支持的内部／底部不以“示意”名义编造。需要标注时标注可读且不抢主信息。

## B. 注意力与阅读顺序：按传播目标检查

先将成图与视觉策略对照：场景、字体、配色与表达强度是否能由本次品牌和使用情境解释？是否只是替换上一产品，却沿用其暖居、冷色、渐变字或卡片布局？品牌推断应仍标为推断；场景合理性不能由颜色好看代替。

新品图预期先识别产品与核心广告语，再能找到型号、首发价，最后读辅助功能与日期；品牌独立可辨。可根据用户目标调整，但必须能明确说出实际第一、第二关注点。

| 检查 | 通过表现 | 失败时优先处理 |
| --- | --- | --- |
| 第一视觉重点 | 产品与核心标题形成关联，画面有明确焦点 | 减弱无关元素，重新组织标题、产品及光影 |
| 名称识别 | 品牌、型号容易定位，型号明显高于辅助卖点 | 调整位置、字重或组间留白，避免只把参数放大 |
| 文案层级 | 标题、辅助句、图标标签与日期有明显重量差 | 减少辅助文字长度、粗度和对比，而非全部缩小 |
| 价格转化 | 有价格任务中金额醒目，币种和条件可读；不压过新品核心主题 | 将金额独立组织，控制周围噪音和条件距离 |
| 信息取舍 | 一个核心购买理由，辅助信息支持它 | 移除非必显重复内容，必显信息重新分组，不擅删 |
| 语言适配 | 中英文均按语义顺畅阅读，数字与单位关联完整 | 分别调整断行与块宽，不照搬中文坐标 |

若第一眼只看到一个巨大技术数字，想不起产品名与购买理由，应确认数字是否真是策略中心；不是就退回调整。

## C. 构图、产品与空间

- 上、下、右边有符合构图的净空，基站和机器人没有同时挤到画布边缘；检查可见轮廓与产品组合包围框，不能仅凭面积比例通过。
- 主要聚焦区、辅助信息区与缓冲区形成疏密节奏；辅助句不会被误读为主标题的一部分，语义分组清楚。净空从字形、产品轮廓和效果外缘检查，不能只比较文字框。缓冲区没有被高对比道具或光效填满。
- 产品清楚突出，同时留有环境空间；大小适合画幅及目标展示，不因缩小而丢失身份识别。
- 左右布局有整体光线、地面或空间联系；穿插／遮挡只在有帮助时采用，型号、价格、标题关键字与产品关键部位不被遮住。
- 产品与背景有足够明度、冷暖或边缘差异；浅色机身没有融入浅色墙面，深色机身仍有材质层次。
- 主光、接触阴影、反射、透视与景深协调；真实场景没有悬浮或尺度错误。概念广告的抽象空间不被误称为真实使用证明。
- 背景、装饰和反射不过度清晰或高亮；强调色有明确归属，不在每个信息块重复争抢注意力。

## D. 字体、图标与功能效果

- 字体符合品类与品牌；精密家电无理由采用笔刷、厚描边或大面积粗斜体时应修改。字体细不自动代表高级。
- 标题基础排版有力度，局部材质或渐变等效果有主题依据且不堆叠。标题下缘渐隐时，完整语义与关键笔画在目标显示大小下仍可辨认；遮挡或褪色造成猜字必须重排，不能仅因采用渐隐就通过。
- 字形实际外缘、图标和装饰之间有合理净空；用户已接受的缩小和留白没有在换字体后丢失。
- 同级图标的线宽、大小、风格、基线一致；标签短而清楚，没有图标比型号更醒目。
- 功能使用小图中能认出产品与对应动作，短文案与画面一致；缩小后不是无法解释的光斑。小图统一身份、色调、边界与文案风格，不误认为额外商品。微距保留真实材质；简单功能不为凑数量硬配图。
- 主功能效果有明确作用对象；局部窗解释看不清的机制，不仅是装饰，不误导为另一个商品或随箱物。
- 局部窗、扫描光、水流、颗粒等没有形成多个竞争主角；若图窗先于整机被注意且不符合策略，应减弱或取消。

## E. 技术交付：必须实测

- 每张文件记录目标宽高与实际宽高，必须完全相等；比例 a:b 用实际宽 × b = 实际高 × a 核验，方向一致。不能以近似比例或改 DPI 代替。
- 核对实际格式、文件大小限制、透明通道、必要色彩／印刷规格；不能只看扩展名。透明图检查有无假棋盘背景及边缘杂色。
- 源稿实际存在、能打开；检查字体替换和资产缺失，并准确说明文字／商品／背景等哪些部分可编辑。整图位图不称为完整分层源稿。
- 原始 Logo 只作为生成参考时不宣称已嵌入原矢量。无法确认的技术指标标明未验证，并阻止依赖它的交付声明。

## F. 审查与修正记录

简短记录：`版本／语言／规格 → 问题及区域 → 用户已认可保留项／尚未评价项 → 可能受影响区域 → 修正内容 → 问题与保留项复核结果 → 用户批准版本与延展范围`。未评价项不记为认可。用户改变默认审查方式时记实际授权，不添加多余确认。

定向修改后与修改前对照：标题是否更可读但变得平淡，氛围是否更合适却失去有依据的使用效果，增加小图是否挤占呼吸空间，调整文字是否使型号或价格失去重点。发现这些回退时继续修正相关区域，不能仅因本轮指出的问题消失就通过。

事实、尺寸、关键文字错误，或视觉上缺少焦点、产品不清、信息争抢时，先定向修正，不将其包装成合格样图。修正后检查受影响区域，并复核商品身份、文案与规格。不能只因为文件检查通过就宣布设计通过；内部检查也不代替默认流程中的样图批准。
