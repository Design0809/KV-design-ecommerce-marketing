# 主视觉验收

G1 展示前检查提案差异；每次实际样图展示前、定向修改后及最终交付前检查成图。按本次视觉类型判断，不把新品价格层级应用于所有任务。

## 观察方式

1. **提案检查**：G1 三案两两比较构图与风格表达，核对共同事实、要求与可实现性；D 后与历史未选方案比较，避免换色或改名重提。
2. **实图对照**：打开实际文件，与原商品、正确 Logo、文案清单及规格表对照；提案文字或提示词不能代替成图验收。
3. **多尺度观察**：目标显示大小检查可读性，缩略图检查注意力顺序；不要求极小预览中的全部辅助文字可读。必要时用允许的灰度预览判断明度。
4. **分项记录**：分别记录通过／需修改／无法验证及具体区域。事实、视觉、技术、G1 选择和样图批准不能合为一个总分。

## A. 事实与商品身份：必须通过

- 商品 SKU、款式、轮廓、比例、颜色、结构、材质、按钮、接口、标签及数量与原素材一致，无错误配件或生成漂移。
- 品牌 Logo 的版本、字形、拼写、图形、比例、颜色和净空正确，商品表面标识没有被重绘成错误形状；参考图品牌未混入。
- 名称／型号、锁定文案、价格、币种、单位、条件和日期逐项准确，无乱码、缺字或变义；发售、预售和活动区间未混淆。
- 利益表达、icon、道具、效果与对比画面没有引入无依据的认证、功效、配方、折扣、销量或赠品。
- 功能表达的对象、作用部位、方向和机制有依据；无素材的内部、底部或背面不以“示意”为由编造。
- 已授权概念商品／视角明确标注，不能作为准确商品展示交付；必要示意标注可读且不抢主体。

## B. 注意力与阅读顺序：按传播目标检查

- 视觉选择可追溯到品牌、商品与使用情境；没有机械沿用上一案例的背景、暖色、科技光效或卡片布局。
- 能指出实际第一、第二关注点，并与本次目标一致；品牌与商品名称可定位，用户必显信息完整。

| 类型／目标 | 通过表现 | 失败时优先处理 |
| --- | --- | --- |
| 新品首发 | 商品、新品价值与名称清楚；要求展示的首发价和发售时间易找到 | 调整商品、名称与利益的关系，减轻辅助参数 |
| 重大促销 | 真实优惠利益明确，商品可识别，价格条件与活动区间可读 | 降低活动装饰噪音，重组金额与条件 |
| 品牌产品 | 产品效果、材质、形态或体验形成焦点，品牌表达一致 | 优化光影、空间与核心概念；不强加促销组件 |
| 混合目标 | 主要目标明确，次级价格或活动信息可读而不抢主角 | 重新分配视觉重量，不将两类信息全部放大 |
| 卖点图／详情页 | 每张或每段重点清楚，按理解顺序展开 | 拆分信息角色，删重复内容；必显内容保留 |

- 图文层级靠尺度、字重、对比、位置和空间共同实现，不能将一组同大同粗文字称为不同层级。
- 技术数字成为第一焦点时，须与策略一致；不因数值大而自动压过产品和利益。
- 中英文分别按语义阅读，数字与单位、金额与条件关联完整。

## C. 构图、产品与空间

- G1 每两案均在商品与文字的构图关系以及风格表达上有实质差异；没有固定 A 极简、B 生活、C 科技的模板。
- 实际成图继承用户选定方向与有效意见；无法实现时说明具体问题，不静默改成另一案。
- 商品组合的关键边缘有合理净空，尺度适应画幅与展示位置；不采用通用面积比例作为唯一合格依据。
- 密集区与缓冲区有节奏，语义分组清楚；按字形、轮廓、阴影与光效外缘判断拥挤程度。
- 商品轮廓与背景可区分，色彩保持身份，暗部仍有材质层次，高光不抹掉标签与结构。
- 光向、透视、反射、接触阴影和尺度协调；真实场景无悬浮或错误接触，概念空间不冒充性能证明。
- 穿插、分区与装饰服务主题，Logo、名称、价格条件、关键文字与商品结构不被遮挡。

## D. 字体、图标与功能效果

- 字体适合本次品牌和方案，基础排版成立；不将细字、黑金、粗斜体或立体字当作通用品质标准。
- 标题效果有主题依据且完整可读；渐隐或遮挡造成猜字必须重排，不能因采用某种效果就通过。
- 指定字体的实际渲染正确；无法确认时不声称应用了精确字体。
- icon 与卖点事实匹配，含义明确，同级线宽、风格、视觉尺寸、基线及间距一致；图标不引入额外认证或功效。
- 不为了凑形式给每项卖点配图；简单信息、动作关系、材质和机制采用适合的形式。
- 使用小图可辨认商品与动作，真实微距保留细节，图窗与商品有关联且不被误认为额外商品。
- 辅助 icon、小图与功能效果的面积、亮度和复杂度服从主次；多个效果没有制造竞争主角。

## E. 技术交付：必须实测

- 每个文件的目标与实际宽高完全一致，方向正确；比例 a:b 以实际宽×b＝实际高×a 核验。
- 按用户定义的交付单位逐项核对语言、尺寸、格式与数量；缩略图、重复链接、内部稿和未完成稿不计入成品数量。
- 实际格式、文件大小限制、透明通道及必要色彩／印刷规格符合要求；透明图无假棋盘背景和明显杂边。
- 源稿存在且能打开，检查字体替换与资产缺失，明确商品、背景、文字等哪些部分可编辑；整图位图不称为完整分层源稿。
- 原始 Logo 仅作为生成参考时，不宣称嵌入了原矢量；无法验证的指标标明未验证，并阻止依赖该指标的完成声明。
- 交付链接或文件实际存在且可用，清单与成品对应；全部本次约定内容完成后才询问可选延展。

## F. 审查与修正记录

| 记录 | 核对内容 |
| --- | --- |
| G1 提案 | 轮次、三案构图／风格特征、差异检查和 A／B／C／D 完整选项 |
| G1 选择 | 用户选择与附带意见；预选、沉默或仅认可某个局部不等于完整方向选择 |
| D 后重提 | 一次 D 一轮新三案，保留事实与要求；历史方案未被换名复用，不编造否定原因 |
| 样图检查 | 版本、语言、规格、事实／视觉／技术结果，与 G1 记录分开 |
| 修改记录 | 问题区域、认可保留项、未评价项、关联影响、修正及回查结果 |
| 样图批准 | 用户明确认可的具体版本与延展范围；方向选择不能替代 |
| 交付与延展 | 本次清单完成情况、可选追加需求与用户选择；不自动扩大任务 |

- 修改后与认可版本对照：可读性提高是否牺牲商品表现，增加小图是否挤占空间，改字体是否让价格或名称失去重点，调整氛围是否损失有依据的功能表达。
- 普通局部修改不重启 G1；用户改变方向时才按实际需求回到方向选择。已明确改变审查流程时记录授权，不增加多余确认。
- 任何商品、Logo、关键文字或规格错误均先修正；视觉缺少焦点、商品不清、信息争抢时也不能包装成合格样图。内部检查不能代替用户样图审查。
