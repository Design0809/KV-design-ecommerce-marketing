# 品类与视觉策略

先按 [视觉方向判断](visual-direction.md) 结合品牌、产品价值和使用场景，再确定购买动机与构图。以下是候选方向，不是固定类别配色或风格；品牌与本次要求优先。

## 传播模式

| 模式 | 第一关注点 | 信息控制 |
| --- | --- | --- |
| 新品营销 | 产品与一个核心购买理由，型号清楚，首发价醒目 | 辅助卖点按理解需求选择小图、微距、图标或短文字，日期与对应价格／发售信息成组 |
| 促销转化 | 真实优惠利益与商品 | 金额／折扣可成为最大文字，优惠条件必须可读，避免虚构原价 |
| 功能说明 | 一个功能机制与对应部位 | 可用局部放大、过程或结构示意，不自动复制到新品主视觉 |
| 品牌形象 | 产品识别与品牌情绪 | 减少参数和促销组件，不强加价格与 CTA |
| 平台白底主图 | 商品身份、外形与数量 | 按平台及用户要求处理，不自动添加场景、图标或文案 |

同一产品可以有不同模式。不能从参考图有很多模块，推断本次也要全部展示。

## 跨品类决策

| 特征/目标 | 可用表达 | 约束 |
| --- | --- | --- |
| 瓶罐、盒装、器具等强轮廓 | 单品英雄、台面陈列 | 保持比例、盖子、标签及套装关系 |
| 布料、皮革、木纹等触感价值 | 实拍细节配主体，侧光 | 不创造新纹路 |
| 金属、玻璃、宝石等反光/透光 | 受控高光、边缘光、简洁环境 | 不抹掉结构，不把透明部分填实 |
| 日常使用价值 | 合理环境与真实尺度 | 不捏造用途，避免悬浮、接触错误 |
| 食用、闻香、清凉等感官动机 | 背景氛围、色彩与感官联想 | 联想与证实的原料/功能分开 |
| 多 SKU、多配件 | 分组陈列、清楚编号 | 先确认包含物，不把道具当赠品 |
| 优惠/活动 | 主体与利益点双重点 | 条件与利益一起可读，不虚构折扣 |

## 类别校验

| 类别 | 常用方向 | 保留/避免 |
| --- | --- | --- |
| 美妆个护 | 包装英雄、清洁质感 | 瓶形/喷头/标签；不暗示未提供的功效或配方 |
| 食品饮料、生鲜 | 真实食物、餐桌、温暖或清爽光线 | 份量/包装/已知原料；不臆造口味、零添加、产地 |
| 服饰鞋包 | 原产品陈列、搭配、纹理 | 版型/图案/拉链/鞋底；不改 Logo、颜色，模特路线按请求决定 |
| 数码家电 | 清楚结构、合理空间 | 接口/按钮/屏幕/数量；不杜撰续航、防水、降噪、兼容性 |
| 家具家居 | 空间比例、材质、生活情景 | 连接结构/木纹；无尺寸时不作精确尺度证明 |
| 珠宝钟表 | 微距、受控反射、留白 | 镶嵌/宝石数量/表盘；不新造证书、纯度、款式 |
| 母婴、宠物 | 温和生活场景、包装识别 | 适用年龄/对象/尺寸；不暗示无依据安全或健康保证 |
| 运动户外、工具工业件 | 功能环境、尺度可信 | 保护件/连接关系；不用装饰创造承载或性能证据 |
| 礼盒、组合商品 | 层次清楚的组合陈列 | 真实 SKU/数量/包装；道具与随箱物区分 |
| 未覆盖品类 | 按形态、材质、动机、环境匹配 | 先锁身份，再设计氛围 |

## 构图与适配

- 方形：保证单品与一个主信息识别；密集信息放次级图。
- 竖版：利用纵向层级，按用途预留上下安全区，避免文案挤压主体。
- 横幅：产品、标题与价格联合试排；可采用左右关系，但用地面、光影、景深或功能效果建立整体空间，不默认硬切成两栏，不为放大商品裁掉关键结构。
- 系列：保持字体、配色、光线与身份，按各张目标变化构图；不同 SKU 使用对应原图。
- 白底图：优先完整外形、数量、自然阴影；用途允许时才加文案/道具。特定平台要求查官方来源。

## 智能家电与精密数码

### 字体与信息

- 品牌规范允许时，优先现代无衬线、稳定正体和清晰数字，借助字重、字距、行长与留白建立层级；不要默认笔刷、粗斜体或厚描边。品牌个性需要时仍可采用展示字。
- 核心标题讲一个有依据的购买理由，型号独立可辨；技术参数作为证据，不自动将最大数字当主标题。
- 首发价是可独立找到的转化区域，金额高于辅助卖点的视觉重量；币种、价格条件和日期不能缩成不可读的小字。
- 简单卖点用统一图标或短标签，需要理解使用关系的功能用小图＋短说明；若用户要求四项全部出现，按容量形成低权重分组，不等于四张大卡片或四组大号粗体。

### 产品轮廓与空间

- 浅色机身避免紧贴同明度背景；可用冷暖差、局部暗部、轮廓光及接触阴影分离，不强制改成深色画面。
- 黑色机身保留暗部层次，用受控边缘光显示曲面和结构，不将表面提亮成灰色或金属材质。
- 基站与机器人按原图结构关系呈现前后层次，产品组合整体留出呼吸空间，尤其检查上、下、右边。保留各自比例；素材不足时不为制造动势重造角度。
- 真实生活场景保持可信尺度；抽象广告场景可用光带、台面或弧面组织空间，不让装饰盖住产品或变成新的视觉主角。
- 画面重点来自轮廓对比、材质、局部清晰度和空间秩序，不等于增加饱和度、黑金配色或持续放大商品。

## 功能可视化方法

先按信息需要选择形式，不以图标或圆窗作为默认答案：

| 信息需要 | 可用形式 | 选择条件 |
| --- | --- | --- |
| 核心功能的作用直观可见 | 主场景中的一个主要效果 | 有事实与可见部位支持，并服务核心广告语 |
| 辅助功能需要动作或环境关系才能理解 | 功能使用小图＋短标题 | 在目标显示大小下仍能识别动作，不挤占主视觉 |
| 材质、工艺、触感价值 | 真实细节微距＋短说明 | 有对应细节素材，不编造纹理或工艺 |
| 简单功能、规格 | 图标或短文字 | 无需另一个场景解释，语义清楚 |
| 内部机制 | 可靠结构依据下的局部图；否则改外部效果或文字 | 剖面与内部结构须有同 SKU 资料；示意标注不能代替依据 |

适合可视化时，新品可用一个主效果配少量辅助小图。数量、边界形式和面积取决于画幅与实际显示大小，不固定一窗、两卡或百分比；功能详情图才按任务提高解释密度。

为拟用效果记录一行：`已证实事实 → 作用部位／方向 → 可见效果 → 夸张边界 → 素材依据／示意标注`。

| 功能事实（须由本次资料证实） | 可采用的表达 | 不得暗示或误画 |
| --- | --- | --- |
| 吸力／吸尘 | 原视角可见吸入口附近的收束气流、少量颗粒轨迹；与地面关系连贯 | 不把气流画成向外吹尘；不推导零残留、除菌或实测吸入距离；未见底部不补造吸口结构 |
| 激光建图／结构光避障 | 对应传感区域的抽象扫描面、地面网格、少量障碍轮廓 | 不把示意光效当真实可见激光，不增加传感器，不承诺资料未给出的精度或识别对象 |
| 热水洗拖布 | 有清洗部位依据时，在局部窗中呈现拖布与冲洗过程及轻微热感 | 不画成向地面喷热水；热水不等于蒸汽消毒，无内部依据不画剖面 |
| 热风烘干 | 有对应部位依据时，以局部暖色气流和简短标签表达 | 不把机身画红、不添加火焰，不从温度推出灭菌率 |
| 滚刷自清洁 | 同型号滚刷细节配少量水流、接触关系和过程表现 | 不替换成另一种刷头，不借参考图的除菌率或认证 |
| 材质／触感 | 用侧光、局部微距及环境反射强调真实纹理 | 不新增纹路、镀层、材质或耐用性结论 |

允许夸张的是已证实功能的视觉表现强度，而不是功能范围、内部结构、参数或效果结论。可能被误认成实测过程或真实结构时，采用简短“功能示意”等标注；标注不能为虚构性能开脱。

### 局部放大窗

- 只在它能解释主画面难以看清的功能时采用；圆形、圆角或自然融合边界按构图选择，不固定圆形模板。
- 放在相关部位附近，通过位置、简洁引导或统一效果建立关联，避开型号、价格和关键商品轮廓。
- 视角与结构需要同 SKU 素材支持；不同放大倍率可以存在，但不能误导为附送的另一件商品。
- 图窗对比和面积低于主体；若它比整机更抢眼，先降低效果亮度、缩小或取消，不同步放大整机补偿。

## 跨品类迁移边界

这些家电字体与功能示意规则不覆盖所有商品：食品可突出食欲和感官氛围，美妆可围绕包装与质地，服饰可围绕版型与搭配。仍需遵守一个主要购买理由、产品保真和明确层级；不得把家电扫描光、水流或深色科技场景带到不相关品类。

### 功能使用小图

- 每张只解释一个动作、利益或使用关系，先选对应的已证实功能，再选外部可见视角；不为丰富画面生成新结构。缺内部素材的洗烘功能可保留文字，选择有外部依据的其他功能做小图。
- 短标题表达功能或利益，必要时补一行说明；不重复主标题、不把全部参数塞进卡片。缩小后只剩不明光斑或无法辨认产品动作时，应减少数量、换更简单视角或改用文字。
- 小图与主画面统一产品身份、色彩和光线逻辑；作为独立说明框或关联细节呈现，让人明确它是同一商品的功能展示，不能误认为另一件随箱商品。
- 边界可用圆角、圆形、自然融合等，按品牌和构图选择。组内统一边界、标题与间距；组与主体之间保留缓冲。
- 主画面有功能效果时，小图降低对比与效果密度；价格或小图所需空间不足时，重新分配信息，不能同步放大主体补偿。

## 同品类也应形成不同方向

- 家电：亲和家庭定位可用自然光、织物和可信使用关系；专业精密定位可用更冷静的空间与受控高光。同样要求清楚轮廓，不统一暖色或冷色。
- 食品：日常早餐可表达生活节奏与真实食物质感；礼赠定位可强调包装组合与仪式感。没有成分依据时不以植物道具暗示配方。
- 鞋包：城市通勤可突出穿搭关系与材质；已有资料支持的户外用途可结合真实环境。缺少防水或耐磨依据时，不以水珠、磨损对比暗示性能。

这些是推理示例，不是预设主题；跨品类保持的是层级、产品保真、空间秩序与可理解性，不是同一配色、标题效果或卡片布局。
