# 品类与视觉策略

先结合品牌、商品价值、视觉类型与使用情境，再选择表现方法。品类提供判断起点，不规定固定配色、构图或字体。

## 传播模式

| 类型／用途 | 第一关注点 | 信息控制 |
| --- | --- | --- |
| 销售转化型：新品首发 | 商品、新品价值与名称识别 | 品牌清楚，真实首发价醒目；发售、预售与优惠日期分别表达 |
| 销售转化型：促销活动 | 真实优惠利益与商品 | 金额／折扣可成为最大信息；名称、条件和活动区间可读 |
| 品牌产品型：产品营销 | 产品效果、核心概念与品牌体验 | 精选卖点，按任务决定价格和日期；克制不等于固定黑白或少字 |
| 卖点展示／功能说明 | 一个利益、动作或机制 | 采用 icon、使用小图、微距或过程表达，不自动塞回主视觉 |
| 商品详情页 | 按购买理解顺序展开产品价值 | 根据资料选择章节，统一视觉，不固定模块数量 |
| 平台白底主图 | 商品身份、外形与数量 | 按平台位置及用户要求处理，不默认增加场景、图标或文案 |

- 两类主视觉是传播方式；卖点图、详情页和白底图是交付用途，不增加第三类主视觉。
- 同一品类可采用任一主视觉类型，渠道只作辅助判断；不把官网、旗舰店或平台入口直接等同于固定风格。

## 跨品类决策

| 商品特征／目标 | 可用表达 | 必须保持 |
| --- | --- | --- |
| 强轮廓、包装识别 | 单品聚焦、台面、空间组合 | 轮廓、比例、标签与真实套装关系 |
| 布料、皮革、木纹等触感 | 实拍细节、侧光、使用关系 | 原纹理、颜色与已证实材质 |
| 金属、玻璃等反光／透光 | 受控高光、边缘光、简洁环境 | 结构细节、透明度和材质身份 |
| 日常使用价值 | 真实场景、动作或合理环境 | 已知用途、接触关系和可信尺度 |
| 食用、闻香等感官体验 | 质地、色彩、情境与氛围 | 区分联想与证实的原料／功效 |
| 多 SKU、多配件 | 清楚分组、编号或组合陈列 | 各 SKU 身份、数量与包含物；道具不是赠品 |
| 价格与活动 | 商品和利益形成清晰主次 | 真实金额、条件和对应日期 |

## 类别校验

| 类别 | 可探索的视觉价值 | 保真重点与边界 |
| --- | --- | --- |
| 美妆个护 | 包装、真实质地、使用体验、品牌情绪 | 瓶形、泵头、标签；植物、液滴和肤质效果不能暗示未知成分或功效 |
| 食品饮料、生鲜 | 真实食物、食欲、包装与食用情境 | 份量、包装、已知原料；不臆造口味、零添加、产地 |
| 服饰鞋包 | 版型、穿搭、织物、生活关系 | 图案、面料、拉链、鞋底和 Logo；模特路线按请求决定，穿着展示需保留商品身份 |
| 数码家电 | 结构、操作、体验、环境或功能关系 | 接口、按钮、屏幕、数量；不杜撰性能、续航、防水或兼容性 |
| 家具家居 | 材质、空间、生活情境和工艺 | 连接结构、木纹、比例；无尺寸时不作为精确尺度证明 |
| 珠宝钟表 | 微距、工艺、反射和佩戴关系 | 镶嵌、宝石数量、表盘；不新造证书、纯度或款式 |
| 母婴、宠物 | 亲和情境、包装和使用关系 | 适用对象、年龄与规格；不暗示未知安全或健康保证 |
| 运动户外、工具 | 合理环境、动作、结构与用途 | 保护件、连接关系；不通过装饰或对比创造承载、耐磨等证据 |
| 礼盒、组合商品 | 包装、陈列、仪式感与组合价值 | SKU、数量、包装；道具与随箱物区分 |
| 未覆盖品类 | 从形态、材质、动机与环境推导 | 先锁定商品与信息，再自由探索表达 |

## 构图与适配

- **方形**：建立商品与主要信息的关系；信息密集时先调整层级与分组，不自行新增次级图交付。
- **竖版**：利用纵向节奏，按实际投放位置保留安全区，不让长文案持续挤压商品。
- **横幅**：联合试排商品、标题和必要价格；左右、中心、非对称等均可，不默认分栏或强裁。
- **系列**：保持身份、字体、色彩与光线的一致性，随各张目标改变构图；不同 SKU 使用对应素材。
- **白底图**：完整外形、数量和自然阴影优先；文案或道具按用途决定，最新平台要求查官方来源。

## 智能家电与精密数码

### 字体与信息

- 品牌支持时可优先稳定正体与清晰数字，通过尺度、字重和行长建立层级；展示字与装饰字并非禁用，须符合品牌方向。
- 技术参数作为证据，不自动压过商品名或核心价值；是否突出首发价取决于本次视觉类型。
- 必显四项卖点不等于四张大卡片；可按理解需要组合 icon、短标签和少量使用小图。

### 产品轮廓与空间

- 浅色机身可用局部明度、侧光或冷暖差分离，深色机身保留暗部层次，不任意改材质与颜色。
- 基站与机器人组合保持真实比例及前后关系，检查组合轮廓的受压边缘；这是家电案例，不扩展为其他品类的固定构图要求。
- 角度与结构由同 SKU 素材支持，不能为三案差异或动势重造未知部位。

## 功能可视化方法

### 从卖点选择表达形式

| 用户需要理解什么 | 候选形式 | 采用条件 |
| --- | --- | --- |
| 简单功能、属性或规格 | 匹配 icon＋短标签，或直接文字 | 语义清楚，有事实依据；不强求每项配图 |
| 动作、使用关系或体验 | 使用场景小图＋短说明 | 商品与动作可辨认，素材与用途支持 |
| 材质、纹理和工艺 | 真实微距／局部放大＋短说明 | 有对应细节素材，不新增纹理或工艺 |
| 直观可见的核心作用 | 主场景中的功能效果 | 对象、作用部位、方向与机制有依据 |
| 内部机制 | 可靠资料支持的局部结构图 | 同 SKU 结构依据充分；不足时改外部效果或文字 |
| 抽象利益或难以图示的内容 | 精简文案与排版 | 不为了配图编造过程或性能 |

- **映射记录**：`卖点／来源 → 需要理解的内容 → 表达形式与理由 → 作用部位／方向 → 视觉权重 → 夸张边界／必要标注`。
- **icon 语义**：依据已证实卖点选择易懂图形，必要时配短标签。盾牌、奖章、医疗符号、植物、水滴等可能暗示认证、安全、功效、成分或防水，使用前检查是否超出事实。
- **icon 风格**：同一组统一视觉尺寸、线宽、填充／描边、颜色、基线和文字间距，匹配本案字体与品牌；不固定所有品类使用线性科技图标。
- **权重分工**：核心利益可进入主场景，辅助卖点承担解释作用。品牌产品型可更少、更融入场景，销售转化型可更直接；两类都不能让辅助 icon 或小图抢走商品和核心信息。
- **数量自由**：根据画幅、实际显示大小和阅读负担决定；无需同时使用 icon、微距、圆窗和主效果，也不固定两卡、三标或统一占比。

### 功能表达的事实边界

| 已证实事实 | 可采用的表达 | 不得新增的含义 |
| --- | --- | --- |
| 吸尘 | 已知作用区域附近的收束气流与颗粒轨迹 | 向外吹尘、零残留、除菌或无依据吸入距离；未见底部不补造吸口 |
| 建图／避障 | 对应区域的抽象扫描面、网格与障碍关系 | 新增传感器、未证实精度；示意光不冒充真实可见激光 |
| 热水洗拖布 | 有部位依据的局部冲洗与轻微热感 | 喷热水洗地、蒸汽灭菌或虚构内部剖面 |
| 热风烘干 | 有依据部位的暖色气流与标签 | 火焰、烧红机身、从温度推导灭菌率 |
| 材质／触感 | 对应真实微距、侧光、环境反射 | 新纹路、镀层或未经支持的耐用性结论 |
| 便携／收纳 | 资料支持的携带情境、匹配 icon | 未知折叠结构、凭空改变商品尺寸或配件 |

- 可以强化的是已证实功能的视觉表达，不是功能范围、参数和结论。必要时注明“功能示意”，标注不能为虚构性能或结构开脱。

### 局部放大窗

- 仅在能解释主画面看不清的部位、材质或功能时采用，形状与边界按品牌及构图决定。
- 用位置、引导或统一效果建立与商品的关系，不误导成额外商品或赠品；避开名称、Logo、价格和关键轮廓。
- 小图抢主体时先降低其对比、面积或复杂度，不同步放大主商品补偿。

## 跨品类迁移边界

- 家电扫描光、水流和科技场景不自动带入食品、美妆与服装；通用的是事实保真、层级、空间与可理解性。
- 品牌产品型不复制某个数码品牌的黑白、渲染角度或字体；按本商品的材质、使用体验与品牌资产推导。

### 功能使用小图

- 每张说明一个动作、利益或使用关系；外观与结构有素材支持，短文案与画面一致。
- 在目标显示大小下能识别商品与动作；变成光斑时简化视角、减少图数或改文字，不补造结构增加细节。
- 与主画面统一商品身份、色调和表达语言；独立框或融合形式均可，避免被理解为随箱附送物。

## 同品类也应形成不同方向

- 家电可呈现亲和生活、专业精度或操作体验；场景与风格由品牌及本次目标决定，不统一暖色或冷色。
- 美妆可围绕包装工艺、真实质地或使用仪式；没有配方依据时不以植物道具暗示成分。
- 衣物可围绕廓形、面料、通勤或已有依据的运动情境；不通过水珠或磨损对比暗示未知性能。
- 食品可突出日常食用、食物质感或礼赠包装；信息层级随销售转化型与品牌产品型目标调整。

### 交付后的延展选择

| 延展类型 | 组织方法 | 素材与验收重点 |
| --- | --- | --- |
| 其他商品视角 | 各张呈现一个有价值的外观方向或组合关系 | 同 SKU 视角图片或可靠结构资料；未知背面不能补造 |
| 卖点展示图 | 一图一核心利益，配必要证据、icon 或可视化 | 功能、图标语义与商品身份准确，避免每张堆所有卖点 |
| 材质工艺图 | 真实微距与整体商品建立联系 | 细节素材充分，不从纹理推导未证实材质或工艺 |
| 使用场景图 | 按人群、地点与动作解释使用价值 | 用途、比例与接触合理；人物路线符合任务 |
| 商品详情页 | 按购买理解需要选择产品概览、利益、功能、细节、场景、规格等内容 | 不固定章节数；无依据的参数、对比、认证和售后内容不补写 |

- 京东、淘宝等可作为商品展示信息组织的参考，实际内容、长度、尺寸和格式以本次要求及具体投放位置为准；不照搬竞品页面。
- 延展由用户选择后才制作。已在本次订单中的视角图或详情页先按约定交付，不作为额外建议再次确认。
- 详情页各屏保持视觉系统，按阅读节奏调整信息密度；静态图片详情页与可编辑页面／源稿的交付范围须说清。
